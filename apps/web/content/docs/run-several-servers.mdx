To run agents on more computers, you don't need a second server: [add a machine](/docs/add-a-machine).

## How switching works

| Where | Behavior |
| --- | --- |
| Desktop app | Shows one server in all windows. Switching reloads every window. |
| Desktop and phone apps | Each keeps its own list of saved servers; the lists aren't shared between devices. |
| Browser | One server per address, so each can have its own tab. |

## Start a second server

- **On another computer:** [install bb](/docs/install) there, or run `npx bb-app@latest`. See [Run bb on an always-on machine](/docs/run-bb-on-an-always-on-machine).
- **On the same computer:** give it its own data directory and ports. The default server uses `~/.bb` and port 38886.

  ```bash
  npx bb-app@latest --data-dir ~/.bb-work --server-port 48886 --host-daemon-port 48887
  ```

To reach it from other devices, see [Set up remote access](/docs/set-up-remote-access). Each server signed in to your bb account gets its own `getbb.app` address.

## Switch between servers

<Tabs items={["Desktop app", "Phone", "CLI"]}>
<Tab value="Desktop app">

1. Open **Window → Server**. It lists **This Mac** (**This Computer** on Linux and Windows), your bb connect servers and your saved servers.

   <Screenshot
     src="/docs-images/run-several-servers/window-server-menu"
     alt="Window → Server lists This Computer, selected, and the saved servers Work and Home lab, with Add Server… below them."
     width={504}
     height={330}
   />
2. To save a server, choose **Add Server…**, enter its URL and an optional name, and choose **Save**.
3. To see your bb connect servers, choose **Sign in to bb Connect…** if it's shown.
4. Choose a server to switch to it.

Or open the command palette and choose **Switch to** *server name*.

To rename or remove a saved server, select it and choose **Edit Server…**; leave the URL empty to remove it.

</Tab>
<Tab value="Phone">

1. Open **Settings → This device → Servers**, or long-press the app icon and choose **Device settings**.
2. Choose **Add server**, then **Connect with bb connect** or enter a **Server URL**.
3. Under **Saved servers**, tap a server to make it active. Long-press it to **Use this server** or **Remove** it.

</Tab>
<Tab value="CLI">

`bb` talks to the server in `BB_SERVER_URL`, already set inside a thread. To target another server for one command:

```bash
BB_SERVER_URL=http://127.0.0.1:48886 bb status
```

</Tab>
</Tabs>

## Use one computer as a machine for several servers

Run **Add a machine** from each server and run each command on that computer. Each server gets its own host daemon, port and folder there (`~/.bb-machines/<server-host>`).

## Check it worked

- **Window → Server** has a check next to the current server, and the sidebar shows its projects.
- `bb status` prints the data directory of the server the CLI is talking to.

## Related troubleshooting

| Symptom | Fix |
| --- | --- |
| A setting or theme is missing after switching | Settings belong to each server. Set them again on the other server. |
| The second server won't start | Another bb uses that [data directory](/docs/bb-wont-install-update-or-start#bb-is-already-running) or [port](/docs/bb-wont-install-update-or-start#port-conflict). Pick a different `--data-dir`, `--server-port` and `--host-daemon-port`. |
| **Edit Server…** is greyed out | It edits only saved and bb connect servers, not **This Mac**. |
