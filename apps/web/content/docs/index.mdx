bb is an open-source app for running coding agents side by side on your own machines. You bring the agents you already use, such as Claude Code, Codex, Cursor and Pi, and bb gives each piece of work its own thread, its own copy of your code, and one place to follow, steer and review all of it.

bb is local-first: your code, agents and threads stay on machines you control. The desktop app, the web app, the phone app, the `bb` CLI and its API all drive the same bb, so anything you can do in the app, you or an agent can also script.

## How bb fits together

- **Thread:** one conversation with one agent about one piece of work. You can watch it live, send it more messages while it works, fork it, or hand it to another agent.
- **Child thread:** a thread started by another thread. A parent can split a task into parts, hand each to a child, and hear back when each one finishes.
- **Project:** a repository bb works in.
- **Environment:** where a thread's code lives. By default each thread gets its own Git worktree, so threads don't step on each other's changes. A thread can also work in your project checkout or a personal workspace.
- **Agent:** the coding agent CLI that does the work. In Settings, agents are called **Providers**.
- **Machine and server:** bb runs a server that keeps your threads, and a host daemon on each machine that runs agents there. One server can use several machines, and you can reach it from a browser or your phone.
- **Plugins and skills:** plugins add features to bb itself; skills are instructions your agents can load.

## Ask your agent about bb

Agents running in bb already have the `bb` command. Ask one how to do something in bb, and it can look it up with `bb guide` and do it for you.
