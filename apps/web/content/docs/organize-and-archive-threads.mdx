Every thread action is in the thread's menu: right-click its sidebar row, or hover and click **Thread actions** (**⋯**).

| To | Menu item | CLI |
| --- | --- | --- |
| Keep it at the top | **Pin** / **Unpin** | `bb thread pin <thread-id>` |
| Rename it | **Rename**, or double-click the name | `bb thread update <thread-id> --title "New name"` |
| Put it away | **Archive** | `bb thread archive <thread-id>` |
| Remove it for good | **Delete** | `bb thread delete <thread-id>` |

You can also drag a thread into **Pinned**. [**Regenerate title**](/docs/name-threads-and-branches#rename-or-regenerate-a-title) asks bb for a new name.

## Group the sidebar

Hover over the **Threads** heading and click **⋯**.

| Option | Choices |
| --- | --- |
| **Organize** | **By project**, **By machine**, **Custom** (your sections), **By environment**, **By read status**; **Provider icons** on or off |
| **Sort by** | **Updated at**, **Created at**, **Alphabetical**; choose again to reverse |
| **Filter** | **Active**, **Archived**, or both |

**Hide from list** in a group's menu moves it under **More**.

```sh
bb thread-list prefs list
bb thread-list prefs set organizationMode machine
```

## Make your own sections

1. Set **Organize** to **Custom**.
2. In the **Threads** heading's **⋯** menu, choose **New section** and name it.
3. Drag threads in, or choose **Move to section** from a thread's menu.

Sections show only in **Custom**. **Remove** in a section's menu moves its threads back to **Threads**.

```sh
bb thread section create "Releases"
bb thread section list
bb thread update <thread-id> --section <section-id>
```

## Archive a thread

Choose **Archive**, or click the archive button on the row. [Child threads](/docs/child-threads-subagents-and-workflows) are archived too.

Archiving stops the agent and closes its terminals. A working agent gets 30 seconds first, so **Undo** on "Thread archived" lets it carry on. To confirm before archiving threads with children, turn on **Thread archive confirmation** in **Settings → General**.

## Find and restore archived threads

1. Open **Settings → Archived threads**, set the sidebar **Filter** to **Archived**, or search with **Search threads** (**Mod+K**) with archived threads on.
2. Click **Unarchive**. An open archived thread also shows **Unarchive** above the box.

```sh
bb thread list --archived
bb thread unarchive <thread-id>
```

## Delete a thread

Choose **Delete**, then **Delete thread**. No need to archive first.

:::warning[Deleting can't be undone]
Delete removes the thread, its child threads, their terminals and the thread's stored files. Archive instead if you might need it again.
:::

## Check it worked

- A pinned thread shows under **Pinned**.
- An archived thread leaves the sidebar and appears in **Settings → Archived threads**.

## Related troubleshooting

- "No thread list plugin is enabled": choose **Thread list** under [**Settings → Appearance → Sidebar thread list**](/docs/change-the-theme-and-layout#choose-labelled-rows-or-the-icon-rail).
- **Move to section** is missing: set **Organize** to **Custom**. Child and archived threads can't be moved.
- An archived thread is missing from search: turn on archived threads in the search filter.
