| To | Do this |
| --- | --- |
| Open Settings | Click Settings at the bottom of the sidebar, or press `Mod+,` (Command on macOS, Control on Windows and Linux) |
| Find a setting | Type in **Search** at the top of the Settings sidebar |
| See settings from a terminal | `bb settings show` prints the server's settings; `bb guide commands settings` lists the commands that change them |

Settings are saved on your bb server and apply to every window and device, except those marked **this device**, which are saved in the browser or app you change them in.

## General

| Setting | What it does | Default |
| --- | --- | --- |
| Navigate to threads on creation | Opens a new thread as soon as you start it. Off keeps you on the New thread screen. This device | On |
| [Default thread followup behavior](/docs/send-steer-and-queue-messages#change-what-enter-does) | What Enter does while the agent is working. **Steer**: Enter sends the message to the agent now, and Mod+Enter queues it until the agent stops. **Queue** swaps the two | Steer |
| Thread archive confirmation | Asks before archiving a thread that has unarchived child threads. The toast after archiving still offers Undo | On |
| Show messages from before a context clear | Keeps a thread's earlier messages visible after you clear its context. The agent doesn't see them either way | Off |
| Summarize shell commands | Shows commands that read, list or search files as a short summary, such as "Searched for …". Off shows each command's text and lets you expand its output | On |
| Setup guide | **Show setup guide** walks you through connecting an agent, adding projects, plugins and devices again. Also `bb settings replay-onboarding` | |
| Open links in the in-app browser | Opens web links inside bb. Desktop app only. This device | On |
| Rewrite localhost links | When you open bb at another address, rewrites `localhost` links to that host so they reach the right machine. Shown only when you aren't on `localhost`. This device | On |
| App links | Lists the apps you chose **Always allow** for, such as `linear://` links, and lets you remove them. Opening app links needs the App links experiment. This device | None |
| Copy on select | Copies terminal text when you select it | On |
| [New branch prefix](/docs/name-threads-and-branches#change-the-branch-prefix) | Added in front of every branch bb creates for a worktree, such as `bb/fix-login-flow-thr_ab12cd34ef`. Leave empty for no prefix. Existing branches keep their names | `bb/` |
| Command line | **Install** puts the `bb` command on your PATH so you and agents outside bb can use it. **Remove** takes it off. Also `bb settings cli-command install`. Shown for the desktop app and `npx bb-app`, not source checkouts | Not installed |
| bb CLI skills | **Install** copies bb's CLI skills into `~/.agents/skills` and `~/.claude/skills` on your machines, so agents outside bb know how to use `bb`. Also `bb skill install-cli-skills` | Not installed |
| Microphone | The microphone voice input records from. This device | System default |
| Streamer mode | Hides your custom models from `config.json` in every model picker, for screen sharing | Off |
| Share anonymous usage data | Sends anonymous usage data such as app starts, setup progress and feature use. Takes effect right away. The `BB_TELEMETRY=false` environment variable turns it off for good | On |
| Show diagnostic events | Shows how bb set up the agent's environment and agent events bb doesn't recognize, for troubleshooting | Off |
| From a terminal | `bb settings general <key> <value>` for the server-wide settings. Keys include `steerActiveThreadOnEnter`, `confirmThreadArchive`, `keepHistoryAfterContextClear`, `summarizeShellCommands`, `terminalCopyOnSelect`, `managedBranchPrefix`, `streamerMode`, `telemetryEnabled` and `showDiagnosticEvents` | |
| Language, 12- or 24-hour time | No setting | |

## Providers

| Setting | What it does | Default |
| --- | --- | --- |
| [Provider list](/docs/connect-your-agents#choose-which-agents-bb-shows) | The agents bb found: Claude Code, Codex, Pi, Cursor and other ACP agents. Drag to change their order in the provider picker. A row's menu sets the **Default** provider for new threads, or **Disable**s a provider to hide it from pickers. Also `bb provider disable <id>` | All found agents; the first is the default |
| Allow faster service tiers | Lets you pick a faster tier, such as Fast, where an agent offers one. Off runs every new turn at the default tier, including queued messages and automations | On |
| [Release idle agent sessions](/docs/bb-is-slow-or-uses-a-lot-of-memory#idle-agents-use-memory) | Stops an agent that has been idle this long, to free memory: ASAP, 5, 10, 30 or 60 minutes. Its thread keeps its history and resumes on your next message. Checked every 5 minutes | 30 minutes |
| Collapse finished turns | One switch per agent. On folds a finished turn's work into one "Worked for" row and keeps the final answer visible. Also `bb settings completed-turns <provider-id> <collapse\|flat\|default>` | On, except Claude Code |
| One agent's settings | Such as Claude Code's sandbox or turning off an agent's own subagents: on its plugin page, see [Plugin settings](#plugin-settings) | |

## Experiments

Every experiment is off until you turn it on, or until **Become an early adopter** turns on those marked Early adopter. An experiment you switch yourself keeps your choice. Also `bb settings experiment <key> <true|false>`.

| Experiment | What it does | Early adopter |
| --- | --- | --- |
| App links | Opens links such as `linear://` or `slack://` in their apps. bb asks first unless you choose Always allow | Yes |
| Changelog preview | Shows the latest release notes on the Updates page | No |
| Compact before resuming expired sessions | When an idle thread holds at least 100k tokens and its prompt cache has expired, offers to compact before your next message | Yes |
| [Server move](/docs/move-your-server-to-another-machine) | Moves your bb server to another machine from **Settings → Machines**, and exports or imports server data with `bb server` | No |
| Plugin updates | Lists plugin updates on the Updates page and counts them in the sidebar badge | Yes |
| Select multiple sidebar threads | Select several threads with Cmd/Ctrl+Shift-click or Shift-click, then act on all of them | Yes |
| Skip notifications for the thread you're viewing | No system notification for a thread that's open in the focused bb window | Yes |
| Thread context card | Shows a thread's changes, pull request and parent and child threads in a card at the top right of the thread | No |
| Thread row metadata | Lets plugins show details, such as a pull request, on a second line under each thread's title | No |
| Pushed timeline updates | Sends an open thread's updates over the live connection instead of reloading them | Yes |
| NEW divider before final assistant message | In a thread that finished while you were away, puts the NEW divider before the final answer instead of the first tool call | Yes |
| Compressed live updates | Compresses large live updates, about 4 times smaller over remote access | Yes |
| Server performance diagnostics | Collects CPU profiles and detailed logs. Shown only when bb was started with `--perf-diagnostics` | No |
