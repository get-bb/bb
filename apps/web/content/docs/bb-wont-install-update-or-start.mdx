| What you see | Likely cause | Fix |
| --- | --- | --- |
| No desktop download for your computer | Builds exist for Apple Silicon Macs, Linux x64 and Windows x64 only | Run `npx bb-app@latest` |
| The Linux AppImage doesn't open | FUSE isn't installed | Install `libfuse2`, or start it with `--appimage-extract-and-run` |
| `Could not locate the bindings file` | npm 12 or later blocked the install scripts bb needs | [Allow the scripts](#could-not-locate-the-bindings-file) |
| npm warns about an unsupported engine | Node.js is older than 22.19 | Install Node.js 22.19 or newer, 24, or 26 |
| "bb is already running" or "Another bb already runs on this data directory" | Another bb uses the same data | [Connect to it or stop it](#bb-is-already-running) |
| "Port conflict" or "port 38887 is already in use" | Another program uses bb's port | [Stop it, or use another port](#port-conflict) |
| "Could not start bb", "Server failed to start" or "bb stopped" | The server crashed | [Read the logs](#the-server-or-host-daemon-wont-start) |
| "Last update failed" in **Settings → Updates** | The update couldn't download or restart bb | Open **View details**; run `npx bb-app@latest` if bb won't come back |
| "Couldn't reach getbb.app" on a company network | A proxy or company certificate blocks bb | [Set the proxy and certificate](#couldnt-reach-getbbapp-check-your-connection-then-try-again) |

## Install the desktop app

Download it for [macOS](/download/macos), [Windows](/download/windows) or [Linux](/download/linux).

<Tabs items={["macOS", "Windows", "Linux"]}>
<Tab value="macOS">

Apple Silicon only. On an Intel Mac, run `npx bb-app@latest`.

</Tab>
<Tab value="Windows">

The x64 installer is in alpha and needs [Git for Windows](https://git-scm.com/download/win). Or run `npx bb-app@latest` inside WSL2.

</Tab>
<Tab value="Linux">

An x64 AppImage in alpha, for distributions as new as Ubuntu 22.04; on arm64, run `npx bb-app@latest`. It needs FUSE: install `libfuse2`, or run:

```bash
./bb-x86_64.AppImage --appimage-extract-and-run
```

</Tab>
</Tabs>

## Run bb with npx

`npx bb-app` needs Git and Node.js 22.19 or newer, 24, or 26. Stop it with Ctrl+C or `npx bb-app stop`.

### Could not locate the bindings file

npm 12 and later block the scripts that build bb's native add-ons. Allow them for one run:

```bash
npx --allow-scripts=better-sqlite3,node-pty,@parcel/watcher bb-app@latest
```

Or for every global install:

```bash
npm config set allow-scripts=better-sqlite3,node-pty,@parcel/watcher --location=user
```

### The bb command isn't found

In the desktop app, open **Settings → General → Command line**, click **Install** next to **bb CLI**, then open a new terminal. Until then, use `npx --package bb-app bb --help`.

## bb is already running

Only one bb can use a data folder (`~/.bb/` by default) at a time. The desktop app says "bb is already running":

- **Connect** opens the running bb.
- **Quit other bb** stops it and its threads, then starts a new one.
- **Quit this bb** closes the desktop app.

`npx bb-app` prints "Another bb already runs on this data directory". Run `npx bb-app stop`, then start again.

## Port conflict

The server uses port 38886 and the host daemon 38887. Find the program using the port and stop it:

<Tabs items={["macOS", "Windows", "Linux"]}>
<Tab value="macOS">

```bash
lsof -nP -iTCP:38886 -sTCP:LISTEN
```

</Tab>
<Tab value="Windows">

```powershell
Get-NetTCPConnection -LocalPort 38886 -State Listen
```

</Tab>
<Tab value="Linux">

```bash
ss -ltnp 'sport = :38886'
```

</Tab>
</Tabs>

Or use other ports with `npx bb-app --server-port 38986 --host-daemon-port 38987`, and set `BB_SERVER_URL` to `http://127.0.0.1:38986` for the CLI.

## The server or host daemon won't start

The desktop app shows "Could not start bb" or "bb stopped"; `npx bb-app` prints "Server failed to start" or "Host daemon failed to start". Read the end of the logs:

- Desktop: **View → Local Logs** shows the desktop, server and host daemon logs.
- Terminal: `tail -n 200 ~/.bb/logs/server-stdio.log ~/.bb/logs/host-daemon-stdio.log`.

"Daemon lock exists - waiting or reclaiming if stale" followed by a failure means [another bb is running](#bb-is-already-running).

## Last update failed

The **Server** row of **Settings → Updates** updates an `npx bb-app` bb and restarts it; from the CLI, run `bb updates app apply`. On failure, open **View details**, then retry.

bb doesn't roll back. If the new version won't start, run `npx bb-app@latest`.

## Desktop updates

The **Desktop** row of **Settings → Updates** shows background downloads. On macOS and Windows, updates install when you quit or click **Relaunch**.

- **"Download failed"**: click retry, or download the app again.
- **Linux never installs it**: the AppImage only updates from a folder bb can write to. Move it to one, such as `~/Applications`.

## Couldn't reach getbb.app. Check your connection, then try again.

bb trusts your operating system's certificates. Set a proxy in bb's environment, then restart bb:

```bash
npx bb-app env set HTTPS_PROXY http://proxy.example.com:3128
npx bb-app env set NO_PROXY .example.com
```

The address must start with `http://` or `https://`. For a company certificate, set `NODE_EXTRA_CA_CERTS` to a PEM file the same way.

## What to send when you ask for help

- `bb --version`, your operating system, and how you run bb.
- `node --version` and `npm --version` if you use `npx bb-app`.
- The exact message, and what you did just before.
- `server-stdio.log` and `host-daemon-stdio.log` from `~/.bb/logs/`.
