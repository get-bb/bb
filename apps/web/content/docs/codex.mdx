Each thread uses its machine's Codex folder (`~/.codex`, or `CODEX_HOME`).

## Set up Codex

1. Install Codex 0.136.0 or newer on each machine that runs its threads. If it's missing or too old, the composer offers **Install Codex** or **Update Codex**.
2. On that machine, run `codex login` with a ChatGPT account or an OpenAI API key.
3. Choose a Codex model in the model picker.

```sh
bb provider models codex
```

## What bb uses from your Codex setup

| From Codex | In bb |
| --- | --- |
| Your Codex config | [MCP servers](/docs/connect-mcp-servers) and other options apply |
| User, project, built-in and plugin skills | In the `/` menu |

## Change Codex settings in bb

Open **Settings → Plugins → Codex provider**.

| Setting | Default | What it does |
| --- | --- | --- |
| Codex memory | On | Lets Codex recall and create memories. |
| Disable provider subagents | Off | Delegates through bb child threads instead. |

```sh
bb plugin config provider-codex set subagentsDisabled true
```

## What's supported

| Feature | Codex |
| --- | --- |
| [Permission modes](/docs/choose-a-permission-mode) | All three; in Approve for me, Codex's reviewer approves |
| Plan | `/plan` gives a plan to approve first |
| Goals | `/goal` sets a goal Codex keeps working toward. Stopping a thread pauses it. |
| Reasoning | None, Low, Medium, High, Extra High, Max, Ultra |
| Speed | Default, Fast, Ultrafast, as Codex reports |
| Daybreak | A model picker switch, if your account has it |
| Forks | [Fork a thread](/docs/fork-hand-off-or-switch-models#fork-a-thread), or edit an earlier message (Codex 0.143.0+) |
| Compaction | `/compact` |
| Rename and archive | Also updated in Codex |
| Questions | Question cards, open up to an hour after the turn |
| MCP and app access requests | A card with Codex's choices |
| Usage limits | ChatGPT accounts, in [Provider usage](/docs/track-usage-limits-and-cost) |
| Several accounts | ChatGPT accounts, through the [Account Pooler](/docs/use-several-accounts) |

Codex accepts model IDs it doesn't list, but your account may not use them. See [Agent feature support](/docs/agent-feature-support).

## Check it worked

Send a message with a Codex model; the reply streams in. A banner or empty model list means Codex is [missing, too old, or signed out](/docs/an-agent-wont-sign-in-or-cant-be-found) on the thread's machine.
