Use this when you want an agent to open a page, click through it, fill a form or take a screenshot, for example to check a dev server it just started.

The browser you open yourself in a thread's side panel is for you. Agents drive a browser through the **Browser Automation** plugin, which comes with bb but isn't installed until you install it.

## Turn on Browser Automation

<Tabs items={["Desktop", "CLI"]}>
<Tab value="Desktop">

1. Click **Plugins** in the sidebar and search for **Browser Automation**. It is listed by BB Official.
2. Click it, click **Install**, then confirm. It turns on when it is installed.
3. To turn it off or on later, use its switch under **Plugins → Installed plugins** or **Settings → Installed plugins**.

</Tab>
<Tab value="CLI">

```sh
bb plugin install browser-automation --yes
```

If you turned it off earlier, run `bb plugin enable browser-automation`.

</Tab>
</Tabs>

You can also ask an agent in any thread to turn it on; it runs the same commands.

## Ask an agent to use the browser

Say which browser you want. The plugin never picks one for you:

| Browser | What it is | Needs |
| --- | --- | --- |
| **Desktop** | A tab in the bb desktop app's own browser, with your signed-in cookies | The bb desktop app open on that machine |
| **Local headless** | A separate Chrome with an empty profile, on a machine you choose | Chrome or Chromium on that machine |

```text title="Prompt"
Start the dev server, then open http://localhost:3000 in a local headless browser on this machine and take a screenshot of the sign-up page.
```

What you see:

- **Local headless:** a live preview of the page in the thread, which you can expand to follow the agent's work.
- **Desktop:** the tab opens in the thread's side panel. While the agent controls it, a bar reads "… is controlling this tab" with **Stop** and **Take over**. Press **Take over** to type into the page yourself.

A headless session closes after 30 minutes without activity. A desktop session lasts at most 30 minutes. Ask the agent to open a new one to continue.

## Sign the bb browser in to your sites

Desktop sessions use the bb browser's own profile. To bring your logins across from another browser:

1. Quit the other browser.
2. Open **Settings → Browser** in the bb desktop app.
3. Choose the browser and profile to copy cookies from.

From a terminal, `bb browser import-sources` lists the browsers it can read and `bb browser import-cookies` copies one. The import is a one-time copy, not a sync, and works only in the desktop app on macOS and Linux.

bb can import from Google Chrome, Chromium, Microsoft Edge, Brave, Vivaldi, Opera, Arc, Dia, Helium, Firefox, Zen and Safari. Arc, Dia, Helium and Safari are macOS only. The bb browser has no browser extensions or passkeys.

## Use Claude in Chrome or Codex Computer Use

These come from the agents themselves, not from bb:

- **Claude in Chrome:** turn on **Claude in Chrome** in the Claude Code provider's settings (**Settings → Claude Code provider**). Claude Code then starts with its Chrome tools. It needs the Claude in Chrome extension in your own Chrome and a claude.ai login on that machine.
- **Codex Computer Use:** when Codex asks to use an app on your computer, bb shows a card titled "Allow Codex to use …?" with **Decline** and, when Codex offers them, **Allow for this session** or **Always allow**. macOS also asks for Accessibility and Screen Recording access the first time. The Computer Use cursor and menu bar icon belong to Codex; turn them off from that icon.

## Check it worked

- **Plugins → Installed plugins** lists Browser Automation with its switch on, or `bb plugin list` shows it enabled.
- Ask an agent to open `https://example.com` in a local headless browser and screenshot it. A live preview appears in the thread.

## Related troubleshooting

- **The agent says no desktop browser is connected:** open the bb desktop app on that machine, or ask for a local headless browser instead.
- **A headless session fails to start:** install Chrome or Chromium on the machine that runs the browser.
- **Settings → Browser says "Only available in the BB desktop app.":** cookie import works only in the desktop app.
- **A browser is missing from the import list:** quit it, then press **Refresh**.
