Switch servers from the sidebar footer in bb Desktop and the mobile app.

## What you get

- A **Servers** item in the sidebar footer. It opens a list of the servers this app keeps, with each server's address and a check on the current one. Choose another to move the window to it.
- **Add server…** opens the app's own add-server screen: bb Desktop's Add Server dialog, or the mobile app's Settings › Servers › Add.
- **Sign in to bb Connect…** appears in bb Desktop whenever its Server menu offers the same sign-in, so your account's servers can join the list.

The plugin is off by default; enable it to add the item. A web browser keeps no server list, so the item is not shown there. Hide or reorder it like any footer item, or disable the plugin to remove it.
