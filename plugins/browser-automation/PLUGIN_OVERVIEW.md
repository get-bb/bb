Let BB browse, click, fill out forms, and check web pages for you. Control the in-app browser or run headless browsers on your local and remote machines connected to BB.

Headless sessions include live inline previews in the chat, so you can watch BB work and expand the preview for a closer look. In-app browser sessions stay visible in BB's browser panel.

Enable Browser Automation in plugin settings, then ask BB to open a page, test a flow, or verify a change.
