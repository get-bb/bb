- Native answers: number fields, sliders, choices, live metrics, line and bar charts, tables, explanations, and interactive diagrams. They run no code and follow bb's theme.
- HTML answers for custom layouts, illustrations, schematic maps, and photos, rendered in a sandboxed frame that cannot reach bb, your cookies, the conversation, or the network.
- Inputs saved with the answer, so they follow you across devices and every open copy updates live.
- An agent that can read your inputs, follow what you do, and drive the answer when you ask it to.
