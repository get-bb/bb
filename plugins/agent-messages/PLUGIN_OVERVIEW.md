Agents answer another agent with `bb thread tell` and answer you in their normal response, so answers meant for an agent stay out of your timeline.

## What you get

- Instructions for every agent: answer an agent that messaged you with `bb thread tell`, answer the user in your normal response, and do not send acknowledgements or restate messages the timeline already shows.

## How it works

The plugin adds no tool. It only adds these instructions, so messages travel exactly as `bb thread tell` already sends them. A change takes effect when a thread's agent session next starts. Disabling the plugin removes the instructions.
