The sidebar navigation, as a plugin.

## What you get

- **New thread**, **Search threads**, **Plugins**, **Skills**, and a row for every plugin panel.
- Drag plugin rows to reorder them, hide any row, and reach hidden rows from **More**.
- Open panels in a split, see where they are open, and read each panel's live count.

## How it works

The plugin draws rows from bb's navigation model. Order and visibility are bb settings (`sidebar.pluginPanelOrder` and `sidebar.visiblePluginPanels`), so they carry over when you switch to another navigation plugin under Settings → Appearance, and **Customize sidebar** opens bb's own editor.
